### BambooMintKey 1.0.0

Bản phát hành đầu tiên của bộ gõ tiếng Việt BambooMintKey.

#### Điểm nổi bật
* Lõi xử lý âm tiết tiếng Việt thuần túy bằng F# Core, biên dịch NativeAOT.
* Hỗ trợ phương pháp gõ Telex cơ bản.
* Tích hợp Text Services Framework (TSF) của Windows.
* Ứng dụng cấu hình giao diện người dùng bằng Avalonia.
* Bộ cài đặt độc lập qua Inno Setup, không yêu cầu .NET Runtime trên máy đích.

#### Cài đặt
1. Tải file `BambooMintKey-Setup.exe` ở mục **Assets** bên dưới.
2. Chạy bộ cài và làm theo hướng dẫn trên màn hình.
3. Hoặc cài qua Windows Package Manager (WinGet) sau khi manifest được duyệt:
   ```powershell
   winget install BambooMintKey.BambooMintKey
   ```
