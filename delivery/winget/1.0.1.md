### BambooMintKey 1.0.1

Bản cập nhật tối ưu hóa phím tắt gõ tiếng Việt và hoàn thiện đồng bộ trạng thái biểu tượng E/V trên hệ thống Windows.

#### Điểm mới và cải tiến trong bản 1.0.1
* **Sửa lại phím tắt gõ tiếng Việt:**
  * Khóa và chuẩn hóa phím tắt chuyển đổi chế độ gõ Anh/Việt (phím dưới phím Esc: phím `~` / `` ` ``).
  * Khắc phục hiện tượng dội phím (echo) khi chuyển đổi focus giữa các ứng dụng và đồng bộ chính xác compartment TSF.
* **Đồng bộ trạng thái biểu tượng E/V trên Taskbar / Language Bar:**
  * Sửa lỗi cập nhật icon trạng thái E (English) / V (Vietnamese) trên khay hệ thống thông qua cơ chế UI thread marshaling an toàn.
  * Ngăn ngừa hoàn toàn hiện tượng xung đột vtable / COM threading gây lỗi crash thư viện `msctf.dll`.
  * Biểu tượng ngôn ngữ hiển thị chính xác theo thời gian thực tương ứng với từng ứng dụng đang kích hoạt.
* **Hoàn thiện bộ cài đặt Inno Setup độc lập (.exe):**
  * Tự động quản lý tiến trình CTF Loader (`ctfmon.exe`) khi cài đặt và gỡ bỏ, giúp áp dụng thay đổi ngay mà không cần khởi động lại máy tính.
  * Sẵn sàng phân phối qua GitHub Releases, WinGet và Microsoft Store (Win32 Store App).

#### Cài đặt
1. Tải file `BambooMintKey-Setup.exe` ở mục **Assets** bên dưới.
2. Chạy bộ cài và làm theo hướng dẫn trên màn hình (hỗ trợ cài đặt im lặng: `BambooMintKey-Setup.exe /VERYSILENT /NORESTART`).
3. Hoặc cài qua Windows Package Manager (WinGet) sau khi manifest được duyệt:
   ```powershell
   winget install BambooMintKey.BambooMintKey
   ```
